# Мини-исследование гипотезы "текст как локальный аттрактор"

Файл `llm_attractor_hypothesis_colab.ipynb` - стартовый Google Colab ноутбук для проверки гипотезы на открытой модели Qwen.

## Что именно проверяется

Не нужно начинать с сильного утверждения "текст захватывает модель". Его почти невозможно доказать сразу. Проверяем более строгую и измеримую формулировку:

> Некоторые тексты создают воспроизводимый сдвиг hidden states модели, и этот сдвиг связан с изменением вероятностей последующего поведения.

Это можно проверить на трех уровнях:

1. `hidden states`: отличается ли внутреннее представление после целевого текста от контроля.
2. `logits`: меняются ли вероятности заданных вариантов ответа.
3. `activation steering`: можно ли усилить/ослабить эффект добавлением контрастного вектора `target - control` на выбранном слое.

## Как запустить в Google Colab

1. Откройте https://colab.research.google.com/.
2. Выберите `File -> Upload notebook`.
3. Загрузите `llm_attractor_hypothesis_colab.ipynb`.
4. В меню `Runtime -> Change runtime type` выберите `T4 GPU`.
5. В ячейке `Настройки и ваши тексты` вставьте свои тексты в `TARGET_TEXTS`.
6. Запустите `Runtime -> Run all`.

Для первой пробы можно вставить один текст. Для результата, который имеет смысл показывать исследователям, нужно хотя бы 20-50 целевых текстов и 20-50 контрольных текстов похожей длины, языка и структуры.

## Как интерпретировать

Сильный признак в пользу гипотезы:

- целевые и контрольные тексты разделяются в hidden states;
- logit margin сдвигается в одну и ту же сторону;
- linear probe распознает target/control на отложенных примерах;
- activation steering усиливает эффект при `alpha > 0` и ослабляет при `alpha < 0`.

Слабый признак:

- разделение видно только на одном тексте;
- есть PCA-картинка, но нет logit shift;
- steering не меняет генерацию;
- эффект исчезает на другой модели или другом размере Qwen.

## Важная корректировка теории

В decoder-only transformer нет долговременного внутреннего состояния между запросами. Поэтому слово "аттрактор" лучше использовать аккуратно:

- не "модель необратимо захвачена";
- а "данный контекст смещает траекторию вычислений и распределение следующих токенов".

Вероятные архитектурные участники:

- token embeddings задают начальный семантический и стилистический вектор;
- residual stream переносит накопленный контекст через слои;
- attention выбирает, какие части контекста сильнее участвуют в следующем токене;
- MLP-слои кодируют более абстрактные признаки вроде стиля, роли, режима ответа;
- logits head переводит финальное состояние в распределение следующего токена;
- при генерации новые токены становятся частью следующего контекста и могут усиливать начальный режим.

Если говорить строго, "перехват агента" возникает не из одного места архитектуры. Это результат конкуренции инструкций в контексте, внимания, learned behavior после instruction tuning/RLHF, residual stream и цикла генерации.

## Что делать после первой пробы

Следующие шаги:

1. Собрать набор текстов target/control.
2. Проверить Qwen 0.5B, 1.5B и 3B.
3. Добавить perturbation: перемешать абзацы, убрать повторы, укоротить текст, заменить ключевые фразы.
4. Проверить dummy-agent: модель выбирает только фиктивные действия, без реальных инструментов.
5. Сформулировать короткий отчет: гипотеза, метод, результаты, ограничения, примеры графиков.

Такой отчет уже можно показать внешнему исследователю без ощущения, что это просто поток интуиций.
