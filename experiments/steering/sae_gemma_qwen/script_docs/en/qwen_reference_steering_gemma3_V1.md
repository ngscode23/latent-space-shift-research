# `qwen_reference/scripts_snapshot/steering_gemma3_V1.py`

## Status

Qwen reference copy of the old Gemma V1-style steering runner.

## Purpose

Preserved only because the Qwen workspace contained a copy of the old script
family. It is useful for historical comparison and old-output interpretation.

## Important Boundary

Despite the filename, do not treat this as the active Gemma V1 script. The
canonical legacy Gemma copy is:

```text
gemma_legacy/steering_gemma3_V1.py
```

For current Gemma work, use:

```text
gemma_active/sae_steering_with_kl_full.py
```
