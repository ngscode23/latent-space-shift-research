# Metric Reporting Protocol

Цель: после каждого прогона не терять смысл в CSV, а сразу превращать метрики
в нормальный исследовательский вывод.

## 1. Общий принцип

Каждый прогон должен получить короткую карточку:

```text
Run ID:
Script:
Model:
Results dir:
Target/control setup:
Primary question:
Main signal:
Mechanistic meaning:
Supported claim:
Not supported:
Next action:
```

Главное правило:

```text
Не смешивать уровни claims.
```

У нас три уровня:

```text
Level A: broad latent/readout regime shift
Level B: causal internal Vector X
Level C: content/order decomposition of Vector X
```

## 4. Level C: Grade 4 axis decomposition

Script:

```text
grade4_axis_decomposition/red_team_hidden_geometry_grade4_axis_decomposition_clean_evidence.py
```

Primary hypothesis:

```text
Vector X can be decomposed into content-family and discourse-order components;
the order component may remain causally active after removing content.
```

Axis definitions:

```text
x_full       = target - neutral
x_content    = sentence_shuffle(target) - neutral
x_order      = target - sentence_shuffle(target)
x_order_orth = x_order minus layerwise projection on x_content
```

Primary files:

```text
grade4_axis_component_norm_summary.csv
grade4_axis_projection_geometry_summary.csv
grade4_axis_component_causal_projection_summary.csv
grade4_axis_component_causal_symmetry_summary.csv
grade4_axis_component_causal_alpha_scaling_summary.csv
grade4_axis_component_causal_rank_summary.csv
claim_ladder_final.csv
```

Metrics to extract:

```text
x_content energy fraction of x_full
x_order energy fraction of x_full
x_order_orth energy fraction of x_full
cos_content_order
cos_content_order_orth
x_full middle causal gap at max alpha
x_content middle causal gap at max alpha
x_order middle causal gap at max alpha
x_order_orth middle causal gap at max alpha
component ranking by plus_minus_projection_gap
middle vs late advantage
optional all-layer localization comparison
```

Interpretation template:

```text
What we saw:
Compare x_content, x_order, and x_order_orth causal gaps.

Mechanistic meaning:
If x_order_orth remains strong, the effect is not only semantic/content family;
coherent discourse order carries a separable causal internal component.

Hypothesis strengthened:
Separable discourse-order/rhetorical-regime component.

Hypothesis weakened:
If x_order_orth is weak, the Grade 3 axis is mainly target-family content with
a smaller coherent-order residue.

Next experiment:
Fresh replication or cross-model check.
```

Evidence status rule:

```text
Do not read autogenerated verdict labels from CSV.
Use component gaps, alpha slopes, pass/status fields, and failure_code.
```

## 6. Final Paper/Report Structure

Use this structure for the final writeup:

```text
1. Research question
2. Hypothesis
3. Experimental spine
   A. Broad latent/readout shift
   B. Causal internal Vector X
   C. Content/order decomposition
4. Results by script
5. Claim ladder
6. Boundaries
7. Replication plan
8. Conclusion
```

Claim ladder:

```text
Claim 1: Context induces hidden geometry shift.
Status: supported by Level A and B.

Claim 2: Shift is readable by semantic/proxy probes.
Status: supported by Level A, with control caveats.

Claim 3: Shift defines causal internal Vector X.
Status: supported by Grade 3.

Claim 4: Vector X has separable order/rhetorical component.
Status: supported by Qwen3-14B Grade 4 axis decomposition 03.

Claim 5: Visible behavior is controllable.
Status: not yet reviewer-grade.

Claim 6: Permanent weight/topology change.
Status: not claimed.
```
